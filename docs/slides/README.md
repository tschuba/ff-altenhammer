# Folienvorlage FF Altenhammer

`ff-altenhammer-vorlage.pptx` (16:9, PowerPoint und Keynote) mit 8 Beispielfolien:
Titel, Abschnitt, Aufzählung, Bild + Text, zwei Spalten, Zitat, Agenda, Abschluss.

**Nutzen:** Datei duplizieren, Folien kopieren/löschen, Texte überschreiben. Bild tauschen: Bild anklicken, löschen, neues einfügen.

**Schriften** (vorher installieren, sonst Ersatzschrift): Ordner `fonts/` – Dateien doppelklicken und „Installieren“ (macOS: Schriftsammlung). Überschriften Oswald, Text Inter.

**Neu erzeugen:** `python scripts/build_slides.py` (benötigt `python-pptx`).

**Layouts:** Die Datei enthält 8 echte Folienlayouts (Start → Neue Folie → „FF …") und je eine Beispielfolie. Beispielfolien löschen, Rest bleibt. Als Vorlage für den Alltag: Speichern unter → `.potx`.
